    Runbook
    
        
      
            
    1. Ahead of time: build recovery media for each host and store the ISO
                somewhere that survives losing that host. Rebuild it whenever the host's disk layout
                changes — a stale image recreates the old layout.
      2. 
            
    2. When a machine is lost: download its ISO and boot the replacement
                hardware from it.
      3. 
            
    3. Issue a recovery token here, for that host.
      4. 
            
    4. At the rescue console, confirm the server address and host name, then type the token.
                ReaR recreates the disk layout and the agent announces itself back to this server.
      5. 
            
    5. Return to Guided recovery and start the restore, choosing the
                announced host as the target. Nothing starts on its own: a bare-metal restore is
                confirmed by you.
      6. 
            
    6. When the restore finishes, the rescue system exits and ReaR installs the bootloader.
                Reboot into the restored system.
      7. 
        
    
        
    
            The server must be able to reach the rescue host directly at the address it announces.
