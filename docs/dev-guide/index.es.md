# Guía de desarrollo

La Guía de desarrollo de HitStor es una referencia interna para compilar, empaquetar, probar y publicar versiones de HitStor. También explica cómo preparar un servidor Ubuntu recién instalado para recibir una instalación de HitStor.

## Temas { #topics }

| Guía | Descripción |
|------|-------------|
| [Panorama del código fuente](codebase-overview.md) | Mapa de la arquitectura, binarios, paquetes y madurez de las funciones. |
| [Entorno de desarrollo](dev-environment.md) | Instale todas las herramientas necesarias para compilar y empaquetar HitStor. |
| [Compilación y empaquetado](build-and-packaging.md) | Compile los binarios y genere paquetes `.deb`, `.rpm`, de Windows y de Docker. |
| [Preparación del servidor](server-preparation.md) | Prepare un servidor Ubuntu antes de instalar el paquete `.deb` de HitStor. |
| [Pruebas](testing.md) | Ejecute pruebas unitarias, pruebas de integración, linting y cobertura de código. |
| [Benchmarks](benchmarks.md) | Tiempos reproducibles de respaldo y restauración (comparación opcional con restic). |
| [Proceso de publicación](release-process.md) | Prepare una versión, genere todos los artefactos y publíquela en GitHub. |
