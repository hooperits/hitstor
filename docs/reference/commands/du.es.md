# hitstor du

Muestra el uso de disco del repositorio.

## Sinopsis { #synopsis }

```
hitstor du [flags]
```

## Descripción { #description }

Muestra el uso de disco del repositorio, con el tamaño total de los archivos de paquete, los archivos de índice, los archivos de instantáneas (snapshots) y el total general.

## Ejemplos { #examples }

Mostrar el uso de disco:

```bash
hitstor du --repo /backups/hitstor --password "secret"
```
